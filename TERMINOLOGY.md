# Глоссарий и правила перевода (EN → RU)

Обращение — «вы» со строчной. Регистр нейтрально-вежливый, как в
локализациях VS Code / GitHub.

## Не переводим

- `worktree`, `PR`, `MR`, имена продуктов: Orca, Claude, Codex, Gemini,
  OpenCode, Kimi, MiniMax, Grok, Antigravity, Cursor, GitHub, GitLab,
  Linear, Jira, Slack, VS Code, macOS, Windows, Linux, WSL, SSH
- CLI-литералы и команды: `orca status`, `AllowTcpForwarding`, флаги,
  имена файлов/конфигов, URL, email
- Логические токены: `OK`, `JSON`, `CPU`, `RAM`, `DNS`, `TCP`, `API`, `ID`,
  `UI`, `URL`, `cron`, `diff` (как технический термин в коде)
- Эндонимы языков в переключателе языка: `English`, `日本語` и т.п.

## Заимствования (пишем кириллицей)

воркспейс (workspace), агент (agent), субагент, сессия, терминал, браузер,
редактор, дифф (diff), ревью (review), коммит (commit), дашборд, промпт,
токен, хост, порт, чекпоинт, снапшот, скилл (skill), инбокс — нет,
Inbox → «Входящие», демон (daemon), крон (cron), онбординг — нет,
onboarding → «первичная настройка», дефолт — нет, default → «по умолчанию»

## Категории статусов агентов (дашборд)

Needs You → «Ждут вас» · Working → «Работают» · Idle → «Простой» ·
Done → «Завершены» · Stuck → «Застряли» · Needs me → «Ждут меня»

## Типы строк

- `…search.<hash>` / `search.*` — скрытые поисковые подсказки настроек:
  переводим строчными ключевыми словами («version» → «версия»).
- Ключи с суффиксами `_one/_few/_many/_other` — формы множественного числа.
  Английских две (_one/_other), русских четыре. Значение по суффиксу:
  _one = 1, 21, 31…; _few = 2–4, 22–24…; _many = 0, 5–20, 25–30…;
  _other = дробные (1.5). Если после числа стоит существительное, можно
  (но не обязательно) добавить недостающие русские формы `_few`/`_many`.
- HTML-сущности (`&nbsp;`), `\n`, ведущие/замыкающие пробелы,
  юникодный `…` или ASCII `...` — сохранять как в источнике.
- Кавычки: внешние — «ёлочки», вложенные — „лапки".
- Не добавлять точку в конце, если её нет в оригинале, и не убирать,
  если есть. Тире: en ` — ` → ru ` — `.
- Если строка — чисто технический токен (URL, `v1.2.3`, `sha256`),
  оставить как есть.

## Плейсхолдеры

`{{value0}}`, `{{count}}`, `{{filename}}` и т.п. — переносить посимвольно,
не переупорядочивать и не переименовывать. В русских фразах допустен любой
порядок слов вокруг них (например, «Не удаётся подключиться к {{value0}}»).
