# orca-russian

Русский язык-пак (плагин) для [Orca](https://github.com/stablyai/orca) —
перевод интерфейса на русский язык.

Каталог переводов — sparse: содержит только переведённые строки, всё
остальное автоматически берётся из английского `en.json`. Плагин работает
на любой стадии готовности — непереведённые места просто остаются
английскими.

## Статус

Каталог переведён полностью:

- **13 660 / 13 676** строк en.json (99,9 %) — не переведены только 5 строк
  с inline-CSS анимированных визуалов (переводу не подлежат, оставлены
  английскими намеренно) и 16 строк защищённого пространства
  `auto.components.settings.plugin*`, которые загрузчик Orca запрещает
  перекрывать.
- Все namespace: настройки, сайдбары, редактор, терминал, браузер,
  GitHub/GitLab/Linear/Jira, онбординг, мобильный компаньон, дашборд,
  трей, меню, скиллы, автоматизации, статистика.
- Для plural-семейств добавлены русские формы (`_few`/`_many` или
  CamelCase `Few`/`Many` — в стиле каждого семейства).

Точное число обновляется скриптом: `python scripts/build.py`.

## Установка в Orca

1. Settings → Plugins → включить систему плагинов.
2. Добавить источник — git URL: `https://github.com/NooBiToo/orca-russian`
   (или путь к локальному чекауту).
3. Установить плагин **Русский** и включить его.
4. Settings → Appearance → Language → **Русский**.

## Структура

```
orca-plugin.json      # манифест плагина (contributes.languagePacks)
locales/ru.json       # собранный вложенный каталог — артефакт, не редактировать
translations/ru.flat.json  # источник: плоские ключи a.b.c -> перевод
work/en.json          # снимок английского каталога из stablyai/orca
scripts/build.py      # сборка + валидация
```

## Рабочий процесс

Переводим в `translations/ru.flat.json` (одна строка = одна запись, удобно
для ревью и диффов), затем:

```bash
python scripts/build.py
```

Скрипт проверяет:

- каждый ключ существует в en.json (исключение — добавленные русские
  plural-формы `_few`/`_many`, которых в английском нет);
- паритет плейсхолдеров `{{...}}` между en и ru;
- правила загрузчика Orca (`parsePluginLanguagePackArtifact`): ≤ 20 000
  записей, глубина ≤ 16, строки ≤ 8 192 символов, никаких `__proto__`/
  `prototype`/`constructor`, точек и управляющих символов в ключах,
  никаких вторжений в защищённое пространство `auto.components.settings.plugin*`;
- предупреждает о строках без кириллицы (случайный пропуск перевода).

Обновление снимка en.json из апстрима:

```bash
curl -sL https://raw.githubusercontent.com/stablyai/orca/main/src/renderer/src/i18n/locales/en.json -o work/en.json
```

## Соглашения перевода

- Обращение — «вы» со строчной (нейтрально-вежливый регистр, как в
  локализациях VS Code и GitHub).
- Плейсхолдеры `{{value0}}`, `{{filename}}`, `{{count}}` и т.п. — без
  изменений. Внутри кавычек — «ёлочки», вложенные — „лапки".
- Не переводим: `worktree`, `PR`, `MR`, имена продуктов (Claude, Codex,
  Linear, Jira…), CLI-литералы (`orca status`, `AllowTcpForwarding`).
- Устоявшиеся заимствования: «коммит», «дифф», «ревью», «дашборд»,
  «воркспейс», «агент», «сессия», «промпт», «хост», «терминал».
- Общепринятые русские термины: «ветка» (branch), «настройки», «фильтр».
- Множественные числа: для русских категорий добавляем ключи
  `_one`/`_few`/`_many`/`_other` (1 агент / 2 агента / 5 агентов);
  `_other` — дробные (1.5 агента). Где полный набор невозможен, используем
  партитивные формулировки («Всего: N», «агентов: N»).
- Промпты-образцы для агента (не UI) пишутся в инфинитиве/повелительном
  наклонении без «вы».
